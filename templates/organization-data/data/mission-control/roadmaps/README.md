# Organization Roadmaps

Concrete `RM-XXXX` roadmap YAML files live here in an Organization-owned `mission-control-data` repository.

This template directory is intentionally empty except for this README. Do not commit real company roadmaps to `MissionControlTemplate`.

Roadmaps follow `schemas/mission-control-roadmap.schema.json` from the app/code template and the model documented in `docs/roadmap-planning-model.md`:

- Roadmap Priority records explain ranked intent.
- Roadmap Step records route execution and must declare whether they are executable.
- Done steps need evidence references.

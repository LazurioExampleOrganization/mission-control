# Mission Control data: rules for agents

- This repository holds the Organization's own plans and roadmaps. It is
  private to the Organization; never copy its records into another
  Organization or into the public Mission Control template.
- Write records through the Mission Control App (a reviewed draft, published as
  one commit) or a pull request to `v3`. Publishing is a Publication: only on
  the user's instruction.
- Never commit anything under `generated/` or `.repository-db/`.
- `schemas/` is generated by Mission Control (`bun run schema:export` in its
  `app/v3`). Change the Zod schema there and copy the result here in the same
  release; never edit a schema here by hand.
- Run `bun scripts/validate.ts` before you open a pull request.
